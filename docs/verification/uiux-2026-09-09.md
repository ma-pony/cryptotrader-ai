# 全站公共组件与 UI/UX 验收

日期：2026-09-09。范围为现有工作区的前端优化，不包含交易架构改造、运行配置变更、提交或推送。

## 设计与实现

- 保持工作台、决策复盘、引擎、账户、研究、系统六个一级入口，复用已有主题和组件库。
- 统一公共标题、操作按钮、空状态、导航路径、内容宽度和移动端布局。折叠导航仍有可访问名称，页面提供跳到主要内容的入口。
- 引擎配置使用四个分区：行情与上下文、信号组件、风控与审批、自动运行。切换分区保留草稿，不自动保存。组件概况和结果入口继续读取后端目录，未新增类型专属前端分支。
- 连接表单区分连接信息、执行选项、凭据和账户读取检查。保存过程中分别显示连接、凭据、检查阶段；修改后不继续展示旧的检查成功状态。
- 工作台与研究页的分析表单只提交分析。修复研究页主按钮没有提交表单的问题；交易按钮仍独立进入交易确认流程。
- 行情页接入公共研究导航与按钮；周期控件采用公共控件样式。图表交易所选择不改变账户执行平台。
- 智能体资料保留技能数据及访问信息，修正旧的“记忆演化”文案；请求失败显示公共错误状态和重试，不显示为暂无记录。
- 浅色成功状态颜色统一加深，不改变深色成功状态颜色。没有增加依赖、参数 JSON 编辑器或旧配置回退。

- 新增或更新的断言覆盖折叠导航名称、本地化面包屑、分区切换保留输入、保存重试提示、连接检查失效、只分析提交、研究导航和技能请求失败。

## 浏览器验收

使用当前源码构建的独立预览，后端为 `tests/workbench_app.py`，临时 SQLite 与测试凭据独立于运行数据库。前端端口 4174，后端端口 8011；应用行情流通过 `VITE_MARKET_STREAM_ENABLED=false` 关闭。行情页既有 TradingView 嵌入仍会读取外部公开行情，不能将本次浏览器验收描述为完全离线。

实际打开并检查的页面：

- 工作台、决策列表、引擎、Kronos 组件详情及配置。
- 账户总览、平台连接及新增连接表单、执行资金池。
- 回测与历史、仅分析、行情看板。
- 模型服务、告警与通知、安全与运行设置、运行指标、智能体资料。

检查结果：

- 在工作台测量 320、375、414、768、1440 像素断点，文档宽度未超过视口。其他页面按窄屏、平板或桌面抽样检查，未见页面级横向溢出。
- 320 像素的配置标签换成两列；连接表单和保存栏可换行；行情周期及交易所按钮的实际高度均为 44 像素。
- 实际输入全局参考周期 `4h`，切换到信号分区后再返回，输入仍为 `4h`，分区保留未保存标记；未提交配置。
- 手机导航抽屉可以打开并进入引擎；深浅主题检查覆盖导航、表单和运行状态。
- 浅色主题关键样本：正文/输入文字 17.87:1、帮助文字 4.70:1；凭据已配置状态由 2.30:1 修正到 5.15:1。
- 隔离后端未提供运行指标和技能数据接口，核对的是错误/重试展示，不是这些接口的真实数据验收。

## 验收边界

- 本轮没有发起分析、回测、真实/官方模拟下单、真实模型调用、Webhook 投递或真实账户检查。自动化中的相关交互使用测试接口，不证明模型效果或交易平台能力。
- 账户/资金池/决策/回测的已填充详情主要由既有自动化测试覆盖，没有把每一种真实数据状态都在浏览器重跑一遍。
- 没有完成每个颜色组合、图表和所有键盘交互的全站可访问性审计，也没有连续扫描 320–1920 像素。Hallmark 检查保留项目已批准的系统字体、六入口结构及语义色，不声称全部 58 项无条件通过。
- 浏览器原生放弃草稿确认框的自动化操作受限，本轮没有以浏览器完成该确认；放弃行为由单元测试覆盖。未写入运行配置，测试标签页随后关闭。
- `localhost:5173` 运行的是旧页面构建，未用它证明新界面已生效，也未重启该服务。独立预览仅用于本轮验收。
- 验收结束后已关闭临时预览标签页及 4174/8011 服务，恢复浏览器尺寸；原有 5173 页面保留。

后续扩展仍优先使用公共组件；新的信号组件或交易平台通过现有后端目录和通用表单接入，不为新类型复制页面。
